# Study inputs

The two protein-ligand complexes used throughout the study. Both targets are
embeddable on the Zephyr topology at the FAM-QUBO sizes reported in the paper.

| File | Description |
|------|-------------|
| `3nq9_protein.pdb` | Receptor for PDB entry 3NQ9. 2584 ATOM records, 162 residues (chain A). |
| `3nq9_ligand.mol2` | Crystallographic reference ligand for 3NQ9. 10 atoms are retained by the AutoDock ligand preparation and become the FAM ligand atoms. |
| `4jsz_protein.pdb` | Receptor for PDB entry 4JSZ. 4046 ATOM records, 257 residues (chain A). |
| `4jsz_ligand.mol2` | Crystallographic reference ligand for 4JSZ. 12 atoms are retained (ten heavy atoms and two polar hydrogens). |

## Origin

The coordinates derive from the RCSB Protein Data Bank entries 3NQ9 and 4JSZ.
The receptor files carry `REMARK GENERATED BY SYBYL (TRIPOS, INC.)`, and the
ligand files carry TRIPOS mol2 headers; the files are used here exactly as
distributed, without further modification.

The ligand `.mol2` files are also the reference structures against which the
in-place heavy-atom RMSD is computed, by atom-name correspondence and without
additional superposition.

## Downstream use

- Pocket feature atoms are generated from the receptor with AutoSite; 13 feature
  atoms for 3NQ9 and 12 for 4JSZ.
- The FAM-QUBO therefore has 130 logical variables for 3NQ9 and 144 for 4JSZ.
- The AutoSite feature-point cloud also defines the docking boxes used for the
  AutoDock Vina baseline, so that Vina and the QA path sample a matched pocket
  region. The box centres and dimensions are reported in the paper.

## Integrity

`SHA256SUMS` in this directory covers the four input files. Verify with:

```bash
cd data && shasum -a 256 -c SHA256SUMS
```

The repository-wide manifest `DATA_SHA256SUMS` at the repository root covers
these files as well.
